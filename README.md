# vidi-patris-docs

Documentação de arquitetura e planejamento do sistema de avaliação de controle parental em vídeos (vidi-patris).

Este repositório concentra decisões cross-repo (visão geral, fases de desenvolvimento, estrutura de projeto e planejamento de épicos) que se aplicam aos repositórios de código:
- [vidi-patris-core](https://github.com/lcaldoncelli/vidi-patris-core) — backend (Python/FastAPI)
- [vidi-patris-video-engine](https://github.com/lcaldoncelli/vidi-patris-video-engine) — processamento de vídeo (C++)
- [vidi-patris-frontend](https://github.com/lcaldoncelli/vidi-patris-frontend) — frontend (React)

## Conteúdo
- [docs/plano-sistema-controle-parental.md](docs/plano-sistema-controle-parental.md) — plano geral do sistema (fases v0/v1)
- [docs/estrutura-projeto.md](docs/estrutura-projeto.md) — repositórios, contrato entre módulos e épicos
- [docs/planejamento-epicos.md](docs/planejamento-epicos.md) — planejamento detalhado por épico, com cenários de teste
